# DayWise — AI Day Planner

Навчальний вебзастосунок на Flask + scikit-learn. Україномовна форма, ML-класифікатор пріоритетів, планування без накладок, фіксовані зустрічі, календарний список, локальні нагадування та експорт ICS.

## Локальний запуск (Windows PowerShell)

```powershell
cd daywise
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Відкрийте http://127.0.0.1:5000

## Приклад введення

```text
Терміново підготуватися до іспиту 90 хв
Зустріч з викладачем о 13:00 45 хв
Придбати продукти 30 хв
Потренуватися 60 хв
Подивитися серіал 45 хв
```

## Як саме використовується ШІ

В `ai_planner.py` побудовано **реальну модель машинного навчання**: TF-IDF за символьними n-грамами + Logistic Regression із бібліотеки `scikit-learn`. На запуску вона навчається на невеликому демонстраційному наборі прикладів і передбачає пріоритет high/medium/low. Додаткові правила коригують очевидні маркери терміновості; парсер регулярними виразами знаходить тривалість і фіксований час, алгоритм розставляє завдання у вільні слоти. Це **демонстраційна**, а не промислово навчена модель; при незнайомому формулюванні можливі помилки. Підключення платного GPT API не потрібне.

## Публікація на Render

1. Створіть порожній репозиторій GitHub та завантажте вміст папки `daywise` **у корінь** репозиторію.
2. У Render натисніть New → Web Service → оберіть цей GitHub репозиторій.
3. Runtime: Python, Build Command: `pip install -r requirements.txt`, Start Command: `gunicorn app:app --bind 0.0.0.0:$PORT`.
4. Оберіть доступний план, створіть сервіс та скопіюйте отриманий URL `https://...onrender.com`.
5. Перевірте `/health` і головну сторінку.

Файл `render.yaml` дозволяє також створити сервіс через Render Blueprint (якщо доступний відповідний план).

## Коротке демо для здачі (30–60 сек)

- Відкрити опублікований вебзастосунок.
- Показати введені п'ять справ, де одна має фіксований час о 13:00.
- Натиснути «Створити розклад», пояснити кольорові рівні пріоритету.
- Показати, що зустріч закріплена на 13:00 та інші завдання не накладаються.
- Натиснути «.ics» й показати імпорт у календар.
- Для сповіщення дозволити повідомлення браузера та створити завдання, що починається за 5 хвилин (сторінку не закривати).
- Записати екран (наприклад, через OBS) і викласти відео з доступом за посиланням.

## Обмеження

- Сповіщення працюють лише коли сторінка лишається відкритою, браузер підтримує Notifications і доступ наданий. У більшості браузерів потрібен HTTPS або localhost; на мобільних браузерах підтримка відрізняється.
- Розклад не зберігається в БД; `.ics` дозволяє перенести його до календаря.
- Час вказується у локальному часі браузера; сервер не зберігає часовий пояс.
- Поділ завдань: один рядок або `;` — одне завдання. Оптимізація евристична, не глобально оптимальна.
